# seabird-RD

Processed data, code and results from O'Brien D.A., Frankish C., Clements C.F., Capdevila P., Wauchope H., Fayet A., Anker-Nilssen T., Bringsvor I.S., Christensen-Dalsgaard S., Dehnhard N., Erikstad K. E., Hodges K., Lorentsen S. H., Reiertsen T. K., Strøm H., Systad G., Tarroux A., Merkel B., Layton-Matthews K. 2026. Behavioural response diversity of individual seabirds correlates positively with colony stability.

## Data sources
- SEAPOP seabird data: Norwegian Institute for Nature Research data portal (https://www2.nina.no/seapop/seapophtml/)
- SEATRACK seabird data: SEATRACK portal (https://seatrack.net)
- ERA5 atmospheric data: Copernicus Climate Change Service Climate Data Store (https://doi.org/10.24381/cds.4991cf48)
